## 👨‍💻 About Me

I'm **Shobhit Rajvanshi**, a Senior Software Engineer at **Josys**, focused on building scalable, maintainable, and high-performance enterprise web applications.

My work centers on frontend engineering, micro frontend architecture, reusable component systems, and delivering reliable user experiences for complex SaaS management platforms.

- 💼 **Current role:** Senior Software Engineer at Josys
- ⚛️ **Core expertise:** React, Next.js, TypeScript, and modern frontend development
- 🏗️ **Architecture:** Micro frontends, reusable components, and scalable UI systems
- 📊 **Product engineering:** Enterprise dashboards, governance workflows, and data-driven interfaces
- 🧪 **Engineering quality:** Component testing, reliable UI states, and maintainable code
- 🚀 **Continuous improvement:** Frontend performance, developer productivity, and engineering best practices
- 🌱 **Currently exploring:** Backend engineering, databases, DevOps, and system design

I enjoy solving complex engineering problems, simplifying user workflows, and building software that remains reliable as applications grow.
