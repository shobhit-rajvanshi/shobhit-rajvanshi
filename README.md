## About Me

I'm **Shobhit Rajvanshi**, a Senior Software Engineer focused on building scalable, maintainable, and high-performance web applications.

My primary interests lie in frontend engineering, application architecture, micro frontends, and creating reusable UI systems that make complex applications easier to build and maintain.

- 💼 **Current role:** Senior Software Engineer at Josys
- ⚛️ **Core expertise:** React, Next.js, TypeScript, and modern frontend development
- 🏗️ **Architecture:** Micro frontends, reusable components, and scalable UI applications
- 🔌 **Integration:** REST APIs, data fetching, and backend integrations
- 🧪 **Quality:** Component testing, reliable UI states, and maintainable code
- 🌱 **Currently exploring:** Backend engineering, databases, DevOps, and system design

I value thoughtful engineering decisions, clean abstractions, practical problem-solving, and continuous learning.
